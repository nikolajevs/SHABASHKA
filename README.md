# SHABASHKA

Маркетплейс универсальных услуг для Латвии. Заказчики и исполнители находят друг друга и договариваются напрямую. Площадка не принимает оплату за работы; платная подписка отложена.

## Первая версия

- Вход через ChatGPT и регистрация аккаунта с ролью заказчика или исполнителя. Роль можно менять.
- Профиль исполнителя: категория, город Латвии, описание, навыки, стоимость, портфолио в виде HTTPS-ссылок.
- Поиск по тексту, категории и городу.
- Публикация заданий заказчиком.
- Один отклик исполнителя на задание; для отклика нужен заполненный профиль.
- Приватный текстовый чат по отклику, обновление каждые 5 секунд при открытом диалоге.
- Выбор исполнителя заказчиком, отметка выполнения.
- Один отзыв с оценкой 1–5 после выполнения, только от заказчика и только выбранному исполнителю. Рейтинг рассчитывается из отзывов.
- Постоянное хранение аккаунтов, профилей, заданий, откликов, сообщений и отзывов в Cloudflare D1.

Примеры профилей показываются только в пустом каталоге, явно помечены и не принимают отклики. Тестовые записи не включены в миграции и не публикуются.

## Стек и запуск

Node.js 22.13+, React 19, TypeScript, Vinext/Vite, Cloudflare Workers, D1, Drizzle. Интерфейс использует существующие Radix/Shadcn-компоненты.

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_medical_sumo.sql
npm run dev
```

Миграцию выполняют один раз на пустой локальной базе. Последующие изменения схемы оформляют новыми миграциями. Локальный сайт запускается на http://localhost:5173. Локальная кнопка входа использует тестовый аккаунт Seedy; в опубликованной версии подмены личности нет.

Локальный профиль исполнения хранится в игнорируемом `.sites-runtime/execution-profile.json`; при отсутствии используется portable. Конфигурация логических привязок находится в `.openai/hosting.json`. Реальные ресурсы и защищённый вход опубликованной версии предоставляются Sites.

## Проверки

```sh
npx tsc --noEmit
npm run build
# В отдельном терминале запустить собранный Worker для локального интеграционного теста:
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js dev --config dist/server/wrangler.json --local --persist-to .wrangler/state --ip 127.0.0.1 --port 5174 --inspector-port 0
node scripts/test-market.mjs
```

Интеграционный тест использует доверенные заголовки личности исключительно в локальном собранном Worker: заказчик, исполнитель, посторонний участник. Проверяет роли, географию, безопасные ссылки, закрытость чата, выбор исполнителя, завершение и ограничения отзывов. Выводит префикс созданных тестовых аккаунтов для точечной очистки локальной базы. Не запускается на внешних адресах. Локальный dev-сервер удаляет переданные клиентом заголовки личности.

В production запросы должны проходить через доверенный Sites dispatcher, который устанавливает заголовки личности. Нельзя выставлять Worker напрямую в интернет с доверием к заголовкам пользователя.

## Админка

Русскоязычная панель доступна по `/admin`; ссылка появляется в личном кабинете администратора. Доступ проверяется сервером по подтверждённому email из Sites и защищённой настройке `SHABASHKA_ADMIN_EMAIL`. Если настройка отсутствует, доступ закрыт всем. Права не зависят от роли заказчика/исполнителя и не могут быть назначены через регистрацию.

Разделы: пользователи, задания, профили, отзывы и журнал действий. Поиск и постраничный просмотр (30 записей). Можно блокировать/восстанавливать пользователей, скрывать/восстанавливать публикации. Каждое изменение требует причины и атомарно записывается в журнал. Собственный аккаунт заблокировать нельзя. Чаты не раскрываются в админке.

Блокировка запрещает все изменения пользователя, включая смену роли, и скрывает его публичные записи. Скрытые задания не принимают отклики, выбор исполнителя и сообщения. Отдельные ограничения сохраняются при редактировании профиля. Скрытые отзывы не входят в публичный рейтинг. Удаления данных нет.

Для локальной проверки UI добавьте `SHABASHKA_ADMIN_EMAIL="seedy@sites.test"` в игнорируемый `.dev.vars`. Для интеграционных тестов запускайте локальный собранный Worker с `--var SHABASHKA_ADMIN_EMAIL:seedy@sites.test`, затем `node scripts/test-admin.mjs`. Локальный тестовый адрес никогда не является администратором production; production-настройка хранится в Sites и не публикуется в репозитории.

## Жалобы и персональные данные

На публикациях доступна жалоба без регистрации; рассмотрение находится в разделе «Жалобы» админки. `/privacy` предоставляет экспорт JSON, деактивацию и подтверждённое удаление. `/legal/terms`, `/legal/privacy`, `/legal/cookies` содержат трёхъязычные проекты документов с плейсхолдерами реквизитов. Письма по обращениям отправляются вручную из админки.

Архитектура, сроки, проверки и незавершённые организационные вопросы описаны в [docs/PRIVACY-AND-NOTICES.md](docs/PRIVACY-AND-NOTICES.md). Для дополнительного локального тестирования используйте `node scripts/test-compliance.mjs` с тем же собранным Worker, что и для тестов админки.

## Границы текущей версии

Это основа MVP для проверки сценариев, ещё не публичный коммерческий запуск.

- Текущий вход требует аккаунта ChatGPT. Самостоятельная регистрация через email/пароль или Google не реализована. Для публичного продукта потребуется выбрать и подключить подходящий публичный провайдер входа.
- Портфолио — ссылки; загрузка фотографий и файлов пока отсутствует.
- Интерфейс доступен на латышском, английском и русском.
- Не добавлены оплата, комиссии, подписки, споры, продвижение, мобильное приложение и сложная модерация.
- До коммерческого запуска нужно заполнить и проверить проекты юридических документов, подтвердить условия хостинга и резервных копий, настроить регулярную очистку и обработку обращений, защиту от массового спама, наблюдение и публичный вход. Отказ от обработки платежей сам по себе не определяет юридические обязанности площадки.

## Поддержка языков

Доступны латышский (LV, по умолчанию), английский (EN), русский (RU) и украинский (UA, код языка uk). Переключатель есть в шапке и в окнах форм. Выбор сохраняется на год в cookie `shabashka_locale`; сервер сразу отдаёт выбранный язык, заголовок страницы и `html lang`. Формат даты и рейтинга зависит от языка. Формы и фильтры при переключении сохраняются. Авторский текст заданий, профилей, сообщений и отзывов не переводится автоматически.

Словарь: `app/i18n/messages.json`; общие функции: `app/i18n/shared.ts`; переключение: `app/i18n/provider.tsx`. Значения категорий и городов в базе остаются стабильными, переводятся только подписи. API принимает `X-SHABASHKA-Language: lv|en|ru|uk`; для ошибок возвращает локализованный `error` и стабильный `errorKey`, чтобы открытая ошибка могла сменить язык без повторной отправки формы.

При запущенном локальном сайте: `node scripts/test-i18n.mjs`. Проверяется полнота словаря, параметры строк, покрытие текста интерфейса, язык серверной страницы, fallback и ответы API для четырёх языков.
